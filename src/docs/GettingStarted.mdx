# Getting started

`@droppy/design-system` is the Droppy design language for developers. It provides Svelte 5
implementations of Droppy components, and a CSS theme. Bits UI is used under the hood (and is
bundled into the package), but Droppy components are themed rather than headless. Bits UI cannot
be used interchangeably.

## Install

Install through NPM. `svelte` (5.x) is a peer dependency, so install it alongside:

```bash
npm install @droppy/design-system svelte
```

To use a specific commit SHA, install Droppy from [pkg.pr.new](https://pkg.pr.new):

```bash
npm install "@droppy/design-system@https://pkg.pr.new/yannbf/droppy-ds/@droppy/design-system@<sha>"
```

## Import stylesheet

Once, in your app entry, import the CSS file. It carries the Droppy tokens and every component's styles.

```ts
import '@droppy/design-system/styles.css'
```

## Use components

Then import components anywhere. No need for `class` props:

```svelte
<script lang="ts">
  import { Button, Input, Modal } from '@droppy/design-system'

  let { isOpen, onClose }: { isOpen: boolean; onClose: () => void } = $props()
</script>

<Modal {isOpen} {onClose}>
  <Input label="Reason" />
  <Button large>Remove</Button>
</Modal>
```
